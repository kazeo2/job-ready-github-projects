## 为什么做这个项目？

GitHub 上有大量优质开源项目，但开发者常常面临一个问题：
**学什么才能真正提升就业竞争力？**

本项目按就业市场的岗位技能需求，对高星 GitHub 项目进行分类整理，
帮助你按职业路径系统地构建技能栈。

## 分类目录

| 分类 | 对应岗位 | 核心技能 |
|------|---------|---------|
| [AI 工程](categories/01-ai-engineering.md) | AI Engineer / ML Engineer | LLM、Agent、RAG、模型部署 |
| [前端开发](categories/02-frontend.md) | Frontend Engineer | React/Vue、TypeScript、工程化 |
| [后端开发](categories/03-backend.md) | Backend Engineer | Java/Go/Python、微服务、API |
| [DevOps 与云](categories/04-devops-cloud.md) | DevOps / SRE / Platform Engineer | Docker、K8s、CI/CD、GitOps |
| [数据工程](categories/05-data-engineering.md) | Data Engineer | ETL、数据仓库、流处理 |
| [移动开发](categories/06-mobile.md) | Mobile Developer | Flutter、React Native |
| [网络安全](categories/07-cybersecurity.md) | Security Engineer | 渗透测试、AI 安全、红队 |
| [系统设计](categories/08-system-design.md) | Senior / Architect | 分布式系统、架构设计 |
| [开发者工具](categories/09-developer-tools.md) | 全岗位通用 | 效率工具、学习资源 |

## 项目收录标准

- **GitHub Star ≥ 5,000**（特殊情况可放宽，但需说明理由）
- **有明确的学习价值**：项目文档完整，代码可读性强
- **与就业技能直接相关**：能帮助开发者获得目标岗位所需的核心能力
- **活跃维护**：最近 6 个月内有提交记录（纯资源列表除外）
- **优先“从零构建”型项目**：借鉴 [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) 的收录原则

## 如何使用

1. 确定你的目标岗位，找到对应分类
2. 从入门级开始，按顺序完成项目
3. 每个项目完成后，在简历中描述你学到的技能
4. 欢迎提交 PR 推荐新项目
